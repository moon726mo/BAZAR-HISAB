# বাজার হিসাব — PWA

এই ফোল্ডারটা একটা সম্পূর্ণ Progressive Web App (PWA)। GitHub-এ আপলোড করে GitHub Pages দিয়ে হোস্ট করলেই এটা:

- ফোনে/PC-তে "Install"/"Add to Home Screen" করা যাবে (আইকনসহ, ঠিক নরমাল অ্যাপের মতো)
- ইন্টারনেট ছাড়াও (100% অফলাইনে) খুলবে এবং কাজ করবে
- অফলাইনে যা যা যোগ/এডিট/ডিলিট করা হবে, সব localStorage-এ সেভ থাকবে; ইন্টারনেট ফিরে এলে Google Sheet সিঙ্ক (যদি সেট করা থাকে) অটোমেটিক হয়ে যাবে

## ফাইল স্ট্রাকচার

```
index.html          ← মূল অ্যাপ
manifest.json        ← PWA মেটাডেটা (নাম, আইকন, থিম কালার)
sw.js                ← Service Worker (অফলাইন ক্যাশিং)
icons/
  icon-192.png
  icon-512.png
  icon-512-maskable.png
  apple-touch-icon.png
  favicon-32.png
```

**সবগুলো ফাইল একসাথে, একই ফোল্ডার স্ট্রাকচারে থাকা জরুরি** — `sw.js` আর `manifest.json` অবশ্যই `index.html`-এর পাশেই থাকতে হবে, নাহলে PWA হিসেবে কাজ করবে না।

## GitHub Pages-এ আপলোড করার ধাপ

1. GitHub-এ একটা নতুন repository তৈরি করো (public হতে হবে ফ্রি GitHub Pages-এর জন্য)
2. এই ফোল্ডারের সব ফাইল (index.html, manifest.json, sw.js, icons/ ফোল্ডারসহ) repository-তে আপলোড করো
   - GitHub ওয়েবসাইট থেকে "Add file → Upload files" দিয়ে drag-drop করা যায়
3. repository-র **Settings → Pages**-এ যাও
4. "Source" এ **Deploy from a branch** সিলেক্ট করো, branch = `main` (বা যেটা আছে), folder = `/ (root)` — তারপর Save
5. কিছুক্ষণ পর একটা লিংক পাবে, যেমন: `https://<username>.github.io/<repo-name>/`
6. ওই লিংকে ফোনে/PC-তে ব্রাউজারে ঢুকে **"Add to Home Screen"** (Chrome/Android) বা **"Add to Dock"** (Safari/iOS) করলেই অ্যাপ আইকন হোম স্ক্রিনে চলে আসবে

## অফলাইন কীভাবে কাজ করে

- **অ্যাপের ডেটা** (দামের লিস্ট, প্রাইস হিস্টরি, শপিং হিস্টরি) সবসময় ব্রাউজারের `localStorage`-এ সেভ হয় — এটা ইন্টারনেট লাগে না, প্রথম থেকেই এভাবে কাজ করত।
- **অ্যাপ নিজেই** (HTML/CSS/JS/আইকন) প্রথমবার লোড হওয়ার পর `sw.js` (Service Worker) এগুলো ক্যাশ করে রাখে। তাই দ্বিতীয়বার থেকে ইন্টারনেট ছাড়াও পুরো অ্যাপ খুলবে।
- **Google Sheet সিঙ্ক** (যদি সেট করা থাকে) ইন্টারনেট ছাড়া সম্ভব না — অফলাইনে থাকলে অ্যাপ এটা এড়িয়ে যায় এবং উপরে "📴 অফলাইন" স্ট্যাটাস দেখায়। ইন্টারনেট ফিরে এলে (`online` ইভেন্ট) অটোমেটিক আবার সিঙ্ক চেষ্টা করে — নতুন করে কিছু করা লাগে না।

## নতুন ভার্সন আপডেট করলে

`sw.js` ফাইলের উপরের দিকে `CACHE_VERSION = 'v1'` আছে। ভবিষ্যতে `index.html`-এ কোনো পরিবর্তন করে আবার আপলোড করলে, ইউজারদের ব্রাউজারে পুরনো ক্যাশড ভার্সন থেকে যেতে পারে। নতুন আপডেট সবার কাছে পৌঁছাতে `CACHE_VERSION` এর মান বাড়িয়ে দিও (যেমন `'v2'`) — এতে পুরনো ক্যাশ বাতিল হয়ে নতুন ভার্সন ডাউনলোড হবে।
